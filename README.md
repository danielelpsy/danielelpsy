### About

I'm a Cyber Security Analyst and vulnerability researcher from Italy, with a focus on offensive security, web and API security, and bug bounty research.

I currently work in cybersecurity while completing a **BSc in Cybersecurity of Systems and Networks** at the University of Milan.

My security research has included findings affecting companies such as **Samsung, Sony PlayStation, Oracle, and Grindr**.
